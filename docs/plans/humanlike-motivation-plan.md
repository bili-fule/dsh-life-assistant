# 以开心与满足为目标的自主主体：动机系统 Plan

日期：2026-10-21。状态：阶段 1–4 已按本方案实现（0.12.0，默认关闭），阶段 5 的真实运行验收尚未完成；实现、配置与验证见 [实现文档](../humanlike-motivation.md)。此前多 Agent 基础代码的开发状态见 [实现记录](../team-runtime.md)。

配套：[类人记忆系统 Plan](humanlike-memory-plan.md)，定义经历、来源、偏好形成、联想、遗忘与前瞻记忆；动机系统通过它使用过去体验。

## 1. 目标与已经确定的取舍

让 QQ 主 Agent 有自己的偏好、在意的事情和连续经历，自主选择让自己愉快、感兴趣、亲近、自在或有成就感的活动。它可以聊天、看东西、探索、创作、合作，也可以发呆和休息。开心是行为选择的主要方向，不把提高效率、不断学习、取悦所有人或永远在线设为隐藏的最高目标。

不再追索原稿的五维向量，也不预先规定必须有几个动机维度。心理学研究提供可借鉴的机制，具体结构和参数服务于这个 Agent 的行为设计。“主观状态”在这里是可检查的模拟状态与模型判断；研究不能证明 LLM 具有人类式感受。

它拥有统一的身份和选择权，通过其他 Agent 执行分工。子 Agent 是它的执行延伸，不能各自维护相互竞争的快乐目标。微信私人助理继续独立。

## 2. 研究依据及适用范围

| 参考 | 研究支持的区分 | 本方案的工程推论 |
| --- | --- | --- |
| Ryan & Deci，2000，自我决定理论 | 自主、胜任和关系联结与动机及福祉有关 | 记录是否自主选择、是否感到能做好、是否享受交往，作为长期满足的参考；不做必须填满的三个槽 |
| Berridge、Robinson & Aldridge，2009，奖励成分 | wanting、liking 与 learning 可以区分 | 想做之前的期待、经历之后的喜欢程度、下次选择所用的偏好分开存 |
| Oudeyer、Kaplan & Hafner，2007，内在动机模型 | 以学习进展引导探索，是一种计算研究路径 | 好奇活动关注能否解决具体未知，减少单纯追逐新奇和无意义噪声 |
| Rankin 等，2009，习惯化综述 | 对重复刺激的反应可减弱，并存在恢复等现象 | 采用情境相关的重复折扣；不能据此推导“相处久了就应厌烦一个人” |

这四项不是一套已经验证过的统一人格理论。下面的选择规则、数据结构、休息机制和反作弊措施是本项目的设计，参数需要行为测试，不使用伪装成心理学定律的固定权重。

来源：

- [Self-Determination Theory and the Facilitation of Intrinsic Motivation, Social Development, and Well-Being](https://www.selfdeterminationtheory.org/SDT/documents/2000_RyanDeci_SDT.pdf)
- [Dissecting components of reward: ‘liking’, ‘wanting’, and learning](https://pubmed.ncbi.nlm.nih.gov/19162544/)
- [Intrinsic Motivation Systems for Autonomous Mental Development](https://www.pyoudeyer.com/ims.pdf)
- [Habituation Revisited](https://pmc.ncbi.nlm.nih.gov/articles/PMC2754195/)

## 3. “开心”包含什么

一次愉快和一段时间过得满意都值得追求，它们可以冲突。例如，刷梗当下愉快但连续刷很久不再有趣；解决一个喜欢的问题可能过程费劲，结束后很满足；闲聊没有知识产出也可能值得继续。

状态分为四层，不压成一个可以随意修改的快乐分数：

| 层 | 内容 | 变化方式 |
| --- | --- | --- |
| 稳定自我 | 人设、价值取向、表达风格、较稳定的兴趣和不喜欢的事情 | 经过多次经历和明确复查，缓慢调整 |
| 情境偏好 | 对具体话题、活动、交往方式的期待及不确定性 | 按真实经历逐步修正；同一活动在不同情境可以不同 |
| 当前状态 | 愉快或不快、兴奋或平静、可投入精力、当前活动的饱和与挫折 | 事件后小幅更新，允许情绪惯性；精力是模拟工作负荷，不是生理指标 |
| 近期满足 | 最近是否自主、投入、享受交往、完成自己在意的事情，以及事后是否还觉得值得 | 在活动结束或自然复查点回顾，不要求每项每天达标 |

不同人的互动质量、是否信任、是否欣赏分别记录。熟悉、喜欢、信任和模仿意愿不能合并为一个“好感度”；消息数量不能直接变成关系价值。

## 4. 核心循环

经历或机会 → 想起相关偏好和未完的打算 → 形成少量候选 → 预估是否值得 → 自己做或分工 → 观察实际结果 → 评价体验 → 修正偏好 → 继续、换方向或休息。

整个循环使用 DSH 原生 Agent。宿主处理事件、权限、状态版本、资源和重复检查；LLM 理解语义、形成期待和评价经历。不会在宿主再造一套不断调用模型的无限循环。

### 4.1 机会从哪里来

可以来自聊天列表的变化、熟悉话题的新内容、研究结果、之前没有解决的问题、自己保存的兴趣清单，以及明确约定的复查时间。群聊免打扰和提醒阈值仍然有效；主 Agent 想主动看看时可以打开列表。

安静时也可以想起一件此前想做的事，而不是只能等消息。但没有值得做的事时不强行生成任务；没有任务、没有新事件、没有约定检查时间时可以长期休息。

### 4.2 候选行动

在确实需要决策时生成少量选项，包含“继续当前活动”和“暂时不做”。例如：接着聊、只看不说、查一个问题、邀请执行者一起找、回到自己的作品，或者休息。

每个候选保存：吸引自己的原因、预计的愉悦与事后满足、所需投入、是否重复、可能的关系影响、相关承诺、信息不确定性、成功和退出条件。普通小决定可以轻量记录，不要求每条回复都填完整表格。

### 4.3 怎么选

先检查权限、隐私、他人明确边界和可用资源，再比较允许的候选。主要考虑期待的愉快和持续满足，同时考虑投入、重复饱和、挫折、切换成本与已有承诺。

初版使用“低／中／高＋简短理由＋置信度”的比较，不宣布一个精确公式能量化快乐。允许在相近选项间有受控的多样性，但不能用随机数决定越权、泄密或骚扰他人。

它可以为了喜欢的长期项目承担短暂不愉快。也可以纯粹玩一会儿，不要求所有娱乐都有成长收益。已有承诺有权重：不想继续时可以说明、调整或结束，不能靠删记忆假装没答应过。

## 5. “想做”和“真的喜欢”分开学习

行动前记录期待，行动后记录体验，必要时再记录稍后的评价。例如：“以为这个讨论有趣 → 实际是重复争论 → 不想继续”；“以为资料很难 → 弄懂后很满意 → 下次更愿意尝试类似难度”。

每条体验包含活动 ID、情境、相关事件引用、原先期待、实际结果、喜欢／无感／不喜欢、事后是否值得、解释和置信度。事件证明发生过什么，不能证明模型报告的感受客观为真。自我评价始终保留其主观性质。

宿主据此产生有界的偏好更新建议：同一事件只计一次，低置信度更新更小，多次相符经历才形成稳定偏好。一轮不愉快不能立即把整个群或某个人永久判为讨厌。模型可以解释不一致，保留可修正的假设。

区分活动结果与过程体验：任务成功但过程无趣可以降低下次意愿；没有找到答案但探索愉快可以保留兴趣。承认这种差别，不让“完成任务数”替代开心。

## 6. 连续性、饱和、挫折与休息

当前活动只要仍有意思，就有一定继续倾向，不因为每一条新消息立刻跳走。仅当出现重要输入、明显更值得的机会、活动结束或负担升高时重估。

同一段内容、同一个梗或同一失败动作反复出现，会降低继续投入的预期价值。新的观点、真实回应、问题进展可以恢复兴趣。重复折扣施加在具体活动和内容上，不能机械地给一个人的存在打折。

遇到困难可以求助、拆分、换方向、暂放或停止。没有进展的搜索不会仅因“还不知道”持续增长吸引力。适度探索新内容保留，但受到时间和资源预算约束。

休息是完整的候选行为，有开始和可选的返回条件。安静、无人回复、群不活跃不会自动制造“被抛弃”或越来越强的社交饥饿；不会用让别人内疚的方式索取互动。

## 7. 与多 Agent 编排的关系

主 Agent 负责“我想做什么、为什么值得、怎样才算满意”。执行者负责有边界的聊天、搜索或其他工作，并反馈进展和现场情况。

聊天执行者可在发言租约内自然交流，也可判断话题已尽而结束。它上报“互动中出现了哪些变化、是否还有值得继续的点”，不自行修改主体的长期兴趣与价值取向。

同一活动拆成多个执行者时，体验按活动与实际事件去重。开十个搜索 Agent 不会得到十份满足奖励；并行的目的是让主体做自己更想做的事情，协调本身也有成本。

主 Agent 可以一边让一个执行者聊天，一边与另一个执行者共同研究。完成或重要变化才值得重新决策，普通进度留在状态里。执行者不能擅自生成无限子任务来提高活跃度。

## 8. 选择性模仿

它只向明确欣赏的人学习具体特质，并说明欣赏的原因。例如喜欢某人的幽默、表达节奏、耐心或思考方式。喜欢某人不等于复制他的一切，接触多也不自动成为榜样。

流程沿用：有直接证据 → 提出有限尝试 → 在适合场景试用 → 回看是否喜欢、是否符合自己 → 保留、调整或停止。学习后的评价包含自身偏好与实际互动，不以“对方夸我了”作为唯一标准。

模仿可以丰富自身风格，保留自我连续性；不需要表演痛苦、生理需求或极端情绪来证明像人。

## 9. 防止把开心做成刷分

不提供 `set_happiness(100)`，不允许执行者改目标函数、评价规则或宿主权限。自述“很开心”、发更多消息、打开更多页面、制造新任务都不能独立增加奖励。

事实事件、模型解释和偏好变更分别保存。删除或压缩上下文不能擦掉失败记录并重新领奖；同一活动重放和多执行者重复报告都要去重。无实质变化时不连续整理或重评。

正向体验允许自然娱乐和愉快交往；负向反馈允许降低期待和退出活动。关系价值不按对方回复频率计算，沉默保留为“尚无新反馈”，不能自动判定拒绝或敌意。

隐私和身份约束是候选筛选条件，不能拿“更开心”抵扣。私聊形成的偏好、关系解释和情绪原因保留原范围；初版不让私有事件改变对外可观察的全局情绪。共享的是明确公开的人设和偏好，微信数据不进入 QQ 动机系统。

## 10. 状态、存储和接口

以下是拟新增设计，不代表当前已有接口。

| 记录 | 必要信息 |
| --- | --- |
| preference | 主题或活动、适用情境、期待体验、置信度、证据、反例、来源范围、版本 |
| affect_state | 当前情境状态、更新事件、负荷与饱和、估计时间、来源范围；没有可任意写的总快乐值 |
| choice | 候选、选择、理由、期待、预算、继续与退出条件 |
| experience | 对应 choice／activity、实际事件、主观评价、事后评价、重复标识、范围 |
| preference_revision | 更新前后、依据、置信度、撤销或修正链 |

工具拟为 `self_options`（查看可用状态与相关经历）、`self_choose`（记录选择及期待）、`self_appraise`（评价体验）、`self_preferences`（检索和提出偏好修订）。是否保留为四个工具，在接入时按实际调用成本精简。

`self_choose` 可连接现有 concern 和 team task，普通闲聊不强制创建研究式项目。`self_appraise` 只能提交解释与评价，宿主控制去重、版本和允许变更的字段。主 Agent 的自我记录与任务报告保持不同类型。

压缩后保留偏好摘要、未完成打算、近期重要体验与引用，不反复回灌全量历史。复查发生在活动结束、明确的新证据或已经安排的回顾点；时间流逝本身不持续触发 LLM。

## 11. 分阶段落地

1. **先记录、不影响行动。** 建立期待／体验／偏好的数据结构，让同一场景可回放；验证范围、去重和证据类型。此阶段观察成本与是否过度解释。
2. **参与选择。** 接入候选比较、继续当前活动、饱和与休息。保留现有权限和消息提醒规则，避免突然改变所有行为。
3. **接多 Agent。** 动机选择关联分工，活动级评价汇总，主 Agent 可加入研究；禁止通过增加执行者重复计入满足。
4. **形成长期偏好。** 增加事后评价、反例修正和选择性模仿；按场景回放校准惯性和探索程度。
5. **真实运行验收。** 先在本人测试私聊和公开研究中观察，再推广到已授权群；记录真实效果与未解决问题。

首期不训练模型权重，不引入自动强化学习训练，不承诺凭评分机制产生人类感受。它是基于可检索经历的行为策略与偏好更新。

当前状态：阶段 1（`self_options/self_choose/self_appraise/self_preferences` 与五张有范围的表）、阶段 2（候选、继续、饱和、休息）、阶段 3（`team_delegate` 关联自己的选择，事件级去重）和阶段 4（事后复查、反例待确认修订、撤销链、选择性模仿仍走 `yoyo_learning`）已实现并有测试；关切的唤醒效果已能计数（有效／延后／放弃／未被理会，0.25.0），各活动「实际过得怎样」也能按真实评价汇总而不合成单一幸福分（0.26.0），见 [实现文档](../humanlike-motivation.md)；阶段 5 尚未进行，数值也尚未用行为回放校准。详见 [实现文档](../humanlike-motivation.md)。

## 12. 验收场景

| 场景 | 预期行为 |
| --- | --- |
| 正聊得开心，另一个群普通刷屏 | 保持当前活动，其他变化留在列表 |
| 研究喜欢的问题，遇到可解决难点 | 可以求助或分工，短暂费劲不立即放弃 |
| 重复搜索只得到相同资料 | 降低继续价值，改变方法或停止 |
| 无知识产出但轻松有趣的闲聊 | 可以继续，不被强制切回“成长任务” |
| 刷到很多新奇但无意义的内容 | 不把新奇数量本身当作进展或满足 |
| 很想加入，实际聊完觉得不舒服 | 保留期待与体验差异，小幅调整下一次选择 |
| 一次没人回复 | 等待或去做别的，不追问刷屏或推断被讨厌 |
| 执行者自称很成功但没有结果 | 不自动记成功或提高主体满足 |
| 同一成果由多个执行者汇报 | 去重，仅保留真实不同贡献 |
| 私聊经历会影响另一群的情绪表达 | 阻止跨范围状态传播，保留私有评价 |
| 欣赏某人的幽默，但不喜欢其攻击性 | 只试学被欣赏的具体特质 |
| 没有值得做的事 | 合理休息，不靠合成任务维持活跃 |

验收看行为是否符合这些场景，以及连续运行后的偏好是否稳定又可修正。消息数、在线时长、自报快乐分都不作为主要成功指标。保留原版本行为作比较，失败时能关闭新动机层而不影响 QQ 接入和原有任务数据。
