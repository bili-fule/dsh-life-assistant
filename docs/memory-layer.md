# 类人记忆层：阶段 1 实现与边界

状态：0.22.0 完成 [Plan](plans/humanlike-memory-plan.md) 阶段 1（来源、版本、撤回传播）、阶段 2 的启发式分段与线索召回、阶段 3（慢速概括与人物印象）、阶段 4 的前瞻记忆（承诺、触发与幂等消费）与提醒效果计数、旧文本记忆的迁移入口；阶段 5 未实现。默认关闭，没有修改生产配置。

这一层只管“经历过什么、依据是什么、后来怎么改或不再使用”，不判断什么值得开心；那部分在 [动机层](humanlike-motivation.md)。原来的 `yoyo_memory / yoyo_recall / yoyo_forget` 继续可用，两者并存，互不改写。

## 开关

```yaml
autonomy:
  memory:
    enabled: false
    recallLimit: 8        # 每次召回最多返回几条概要
    migrateLegacy: false  # 启用时把旧 yoyo_memories 逐条登记为待核实主张（只做一次）
```

关闭时没有这七个工具，行为与之前相同。

## 七个工具

### memory_recall

按线索想起当前范围内的经历与主张，只返回概要与引用。线索可以是话题、参与者或某段经历；`used` 用来声明这次真的用到了哪几条，只有那时才增加使用计数。默认不返回 `simulation` 类型，需要时显式 `includeSimulation`。

排序考虑：命中线索数量、未解决事项、是否淡出、是否很久没有更新、有效使用次数。**读取本身不加分**。

### memory_inspect

核对一条记忆的依据：返回记录本身、每个来源是否仍可用，并可用 `source` 按 `offset/characters` 分页读原始消息、工具回执或网页正文（`verbatim:true`）。授权被撤回、回执过期或原文被删除时，来源标为不可用而不是静默省略。

### memory_propose

- `kind:'episode'`：记录一次经历。必需 `title`、`what` 和至少一条来源；可写 `scene / role / turningPoint / outcome / unresolved / expectation / appraisal / laterAppraisal / occurredFrom / occurredTo`。参与者由宿主从被引用的原文推导，不接受模型自报。
- `kind:'claim'`：记录一条主张。必需 `claimType`、`statement`；`evidence` 与 `counter` 分别记录支持和反例；`person` 用于关于某人的记忆。
- 传 `claim` 表示修订已有主张：必须带来新的来源，旧版本保留在修订链里。

### memory_retract

`fade` 淡出、`archive` 归档、`retract` 撤回、`forget` 忘记：

- 淡出只降低召回优先级，原文保留。
- 归档退出日常召回，概要与来源仍可核对。
- 撤回沿 `derived_from` 关系传递到引用它的主张，并留下最小墓碑。
- 忘记在撤回之外，把该记录用到的每个来源登记为墓碑，任何新记忆都不能再用这些原文形成；换一种说法摘要同样被拒。

原文删除不在本层，仍是原有的记忆退役与账本记录流程；文档明确区分“不再使用”和“删除”。

### memory_segments

把一个窗口的新消息切成**候选分段**：起止编号、条数、真实发送者、边界原因（`window_start / gap / attachment / length / topic_shift`）与开头预览。边界依据是时间间隔（默认十分钟）、附件或转发、以及相邻消息的用词重叠（中文按双字组比较，低于 2% 视为换话题）。

分段只是候选，不是记忆：宿主不替你决定哪段值得记、当时是什么感受。值得留的用 `memory_propose` 写成经历，`evidence.range:{from,to}` 可以直接引用这一段（最多 40 条），由宿主展开成真实原文。

### memory_intent

前瞻记忆：承诺、打算与等待中的事。无参数查看当前范围未结束的事；新建需要依据（哪句原文让你记下它）、事项、类型（`commitment` / `intention` / `waiting`）与触发方式：

- `time`：到 `dueAt` 时由宿主调度，`dueAt` 最远 90 天。
- `window`：指定窗口出现**创建之后**的新消息时触发。
- `explicit`：不做自动提醒，只留记录。

`commitment` 必须有完成条件或触发时间。触发只发生一次：时间触发放过之后，同一个到期时间不会再响；窗口触发消费时记录到当时的最后一条消息，之后的新消息才会再次唤醒。提醒通过原生边界的事件 `memory_intent_due` 呈现，不每分钟轮询模型。

结束需要的不是一句总结：`done` 要么给出当前范围内**非自述类**的工具回执（自己写过的活动、关切、记忆都不能证明做过），要么由主体显式 `confirmed:true` 确认，并标记为自述；`dropped` 必须说明理由。已完成或已放弃的记录不再提醒。

### memory_generalize

从多段经历慢慢概括：这是「慢速」形成主张的入口，和单条原文的 `memory_propose` 分开。

- 至少两条**独立**经历；同一条经历不能重复计数，若后一段引用的原文都已被前一段用过，视为同一来源，不能算两次。
- 置信类型由宿主按规则推导，模型不能自称「观察」：三条以上、且每段都是自己参与或亲自观察 → `observed`；两条 → `inference`；有反例 → 退回 `inference`；经历里有执行者报告或转述 → 记成 `worker_report` / `told`。
- 反例作为独立字段保存，不会被静默忽略；已概括的主张遇到新反例应另写一条或修订，而不是改写历史。
- 概括会链接到它的每段经历（`generalizes`），所以撤回其中任何一段经历都会连带撤回这条概括——重新写出同样的结论也只能基于剩下的证据重新形成，且置信类型更弱。

人物印象按维度分开保存：`familiarity`（熟悉）、`trust`（信任）、`liking`（喜欢）、`admiration`（欣赏）、`imitation`（想模仿）。每条只描述一面，没有把它们合成一个好感分数；关于某个人的印象必须有同一真实身份的直接原文。

## 旧记忆迁移

原有的 `yoyo_memories` 文本记忆可以用 `migrateLegacy()` 逐条登记到新结构（或配置 `memory.migrateLegacy: true` 在启用时执行一次）。规则：

- 每条旧记录变成一条 `inference` 主张，`body.needsReview:true`，并在 `body.legacy` 中保留原编号、类型与旧置信类型；**迁移不会提高可信度**。
- 资料范围原样继承；同一条文本在同一范围已存在时跳过。
- 已迁移的旧编号记在 `yoyo_memory_migrations`，重复执行不会重复登记。
- 旧记录本身不改、不停用：它仍是原文索引，等主体按新结构逐条核实后再决定保留或退役。

## 提醒的效果

每次真正送达原生边界的提醒都记一行 `yoyo_memory_wakes`。之后只有两种结局算数：关闭事项时记成 `done`（有真实回执或明确确认）或 `dropped`（说明理由放弃）；如果同一事项又被唤醒、而上次提醒还没关闭，上一次就记成 `ignored`——**没有被理会的提醒不算成功**。

因此：

- `memory_intent` 列表里每条事项带 `wakes:{delivered,done,dropped,ignored}`，动态状态只给汇总计数，不含事项正文；
- 同一事项连续三次没被理会（`NAG_LIMIT`）后，窗口触发不再唤醒，列表里标 `nagMuted:true`；想恢复就先办完或明确放弃，而不是靠反复提醒撑注意力；
- 时间触发本来就只响一次，不受这条限制；
- 计数按范围过滤，私人事项的唤醒次数不会出现在其他窗口。

## 记录

| 表 | 内容 |
| --- | --- |
| `yoyo_memory_episodes` | 标题、场景、角色、发生了什么、关键转折、结果、未解决事项、当时的期待与评价、稍后的重新评价、真实参与者、来源引用、范围、状态、版本、时间区间 |
| `yoyo_memory_claims` | 主张、类型、主题或人物身份、适用情境、支持与反例、置信类型（`observed / told / worker_report / inference / self_report`）、状态、版本、所属经历 |
| `yoyo_memory_links` | 派生与引用关系（经历 → 实体、主张 → 经历） |
| `yoyo_memory_revisions` | 每次修订的前后版本与依据 |
| `yoyo_memory_retractions` | 最小墓碑：对象编号、理由、范围，不含被要求忘记的正文 |
| `yoyo_memory_uses` | 有效召回记录（只在主体声明用上之后写入） |
| `yoyo_memory_wakes` | 每次送达的提醒与结局（完成／放弃／未被理会），不含事项正文 |
| `yoyo_memory_migrations` | 已迁移的旧记忆编号与新主张编号，保证只登记一次 |

## 来源规则

- 每条记录都要求至少一条当前可见的原文、工具回执或网页来源；范围是这些来源与当前视图的并集。
- **身份**：关于某个人的主张必须由同一 `[平台, 账号, 真实发送者编号]` 的直接原文支撑。转发内容是引文，自己发出的消息不是对方身份依据，不同人的原文不能拼接；同昵称的两个人因此不会被合并。
- **概括不是来源**：支持来源按 `event:/receipt:/document:` 编号去重，同一条原文引用十次仍是一个来源。
- **不能升级**：重复回忆不会把 `inference` 变成 `observed`；升级需要新的直接消息或工具回执（网页来源不算直接观察）。
- **已验证方法**：`procedure` 的 `observed` 必须有真实工具回执，否则只能是 `inference`。
- **模拟**：`simulation` 不能标 `observed`，默认不参与召回，`memory_inspect` 会显式标 `simulated:true`。
- **执行者报告**：只有执行者转述的内容用 `worker_report`，不写成主体亲自观察。

## 撤回传播

`retract` 从被撤回的记录出发，沿 `yoyo_memory_links`（`derived_from / supports / part_of`）和 `yoyo_memory_claims.episode_id` 做广度优先遍历，把所有依赖它的主张一起撤回，并各自留下墓碑。往返撤回的结果是：召回、`memory_inspect`、以及后续提案都被拦住，不会因为重新摘要复活。

## 验证

`test/memory-layer.test.mjs`（17 项）：

1. 经历保留真实发送者，转发与混合身份被拒；
2. 重复来源不再计数，推断不能被重复回忆升级；
3. 私人经历不进入其他窗口或公开视图；
4. 忘记后同一条原文无法再形成记忆，墓碑不含正文；
5. 撤回经历会一起撤回派生主张；
6. 换一种说法的线索仍能想起，找不到时不编造；
7. 模拟只作为设想保存，默认不召回；
8. 核对可分页读原文，撤权后来源失效；
9. 已验证方法需要工具回执，使用计数只在实际用上后增加；
10. 候选分段按间隔、换话题与附件断开，且不会自动变成记忆；
11. 分段范围可以作为来源引用（有上限），同一主张修订后召回只出现一次；
12. 承诺按窗口新消息触发一次，之后的新消息才会再唤醒；完成需要真实回执或明确确认，自述类回执被拒；
13. 时间触发只在到期后出现、同一到期时间只响一次，私人承诺在其他窗口不可见，撤权后不再提醒；
14. 概括需要独立经历、同一批原文不能算两次，两条为推断、三条相符为观察，含反例退回推断，撤回支撑经历会连带撤回概括；
15. 同一人的熟悉与信任分开保存，缺少维度或身份依据会被拒绝；
16. 旧文本记忆迁移为待核实主张、范围继承、不重复登记，旧记录保持可用；
17. 提醒的送达与结局都被记下，连续三次没被理会后安静下来，关闭后计数归位且不出现在其他窗口。

`test/social-agent.test.mjs` 另验证：未配置时没有这些工具；后台整理可用召回、核对、提案、分段与概括，但 `memory_retract` 被宿主拒绝；这些工具的回执不能当作执行证据；动态状态只暴露计数摘要；到期的承诺在原生边界唤醒一次并被消费，且计入送达次数。

## 与 Plan §15 的差距

已实现（阶段 1、阶段 2 的分段与召回、阶段 3、阶段 4 的前瞻记忆、旧记忆迁移入口）：来源类型、身份约束、支持来源去重、修订链、淡出／归档／撤回／忘记、撤回传播与防复活、按权限过滤的召回与核对、使用计数、模拟隔离、边界启发式分段、线索排序（关键字与中文双字组、参与者、未完成事项、有效使用）、承诺与等待的时间／窗口触发与幂等消费、多经历概括与分维度人物印象、旧 `yoyo_memories` 逐条迁移为待核实主张、提醒的送达与结局计数（连续未理会即安静）。

未实现：

- **阶段 2 余下部分**：语义向量检索（真正的同义改写仍可能错过）、跨窗口的关联召回（现在只在当前视图内）、影子对比旧检索的成本与相关性。
- **阶段 4 余下部分**：执行者提交记忆候选、工作记忆包与并发版本控制。
- **阶段 5**：夜间整合策略、超长输入分块、重启与撤权恢复的行为验收。
- 旧 `yoyo_memories` 只有一次性迁移入口（`migrateLegacy()` / `memory.migrateLegacy`）：迁移后仍需主体逐条核实，旧记录本身不会自动退役，也没有批量重建原文索引或反算范围的工具。
- 动机层的偏好与本层的概括仍是两套记录：动机层管「这次值不值得」，本层管「我记得什么、依据是什么」，尚未自动互相写入。
- 没有真实模型与真实群的连续观察；只有确定性测试。
