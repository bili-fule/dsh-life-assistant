- 真实 QQ 文件、长合并转发及转发附件的输入验收；多群授权后的实际身份与窗口切换观察。

- 从已验证操作形成可复用 Skill 的完整保存、复测、版本与启用流程；目前为有回执依据的 procedures 记忆。
- 隔离环境中的依赖获取，以及指定项目部署、服务管理等额外固定权限接口；现有执行任务没有网络。
- 主动发言节奏与夜间打扰控制、长期资源与任务归档；现有模型步骤预算、暂停及观察模式仍生效。
- 连续多日观察兴趣、关系、动机、情绪与自己的计划是否能形成自然行为。字段、提示和一次成功联调不能证明这一点。

## 0.13 类人记忆层阶段 1

新增 `src/memory-layer.mjs`：六张表（`yoyo_memory_episodes / claims / links / revisions / retractions / uses`）与四个原生工具 `memory_recall`、`memory_inspect`、`memory_propose`、`memory_retract`，默认关闭，配置为 `autonomy.memory`。经历与主张都要求当前可见的来源；参与者由宿主从原文推导；转发、自己的消息和混合身份不能成立关于某个人的记忆；同一原文重复引用仍是一个来源，重复回忆不能把推断升级为观察；淡出、归档、撤回与忘记分开，撤回沿派生关系传递，忘记会登记来源墓碑阻止重新摘要复活。后台整理可以使用召回、核对与提案，但不能撤回。

插件测试 183 项（新增 9 项记忆测试、1 项工具门禁测试）与语法检查通过。未部署；阶段 2–5 与旧记忆迁移仍未实现。

## 0.15 任务级用量台账

新增 `yoyo_team_usage`：执行者每一步与 Token 都按任务与尝试分行记录，日预算仍另记在 `yoyo_usage`。预算门禁改为读取数据库计数，重启或新宿主实例不会重新发放预算；超额那一步被拒绝，执行者随之阻塞。`team_overview` 只给步数与 Token 汇总，`team_inspect`、`team_deliberate` 在原资料范围给完整用量；原生运行时未报告 Token 时记 0，不估算。

插件测试 187 项（新增 2 项：按尝试分行的用量在重启后不重置、宿主步数门禁写入台账）与语法检查通过。未部署；执行者会话恢复、更多角色与管理页仍未实现。

## 0.16 执行者身份复用与续租

执行者身份改为由任务编号派生，同一任务的后续尝试复用同一 DSH 工作目录与原生会话。每一步同时续租，期限检查读取续租后的实际时间而不是启动时的快照。失败次数与重试时间入库：自动重试默认关闭，打开后只在尝试次数内重排到期任务；发送状态为 `uncertain`／`sending` 的任务永不重排，重启产生的阻塞也不会自动续跑。

插件测试 190 项（新增 3 项：身份复用与尝试计数、续租上限与重试边界、有界重排且跳过未确认发送）与语法检查通过。未部署；真实模型下的续跑质量、更多角色与管理页仍未实现。
